# Premium Analog & Digital Clock 

A beautiful, glassmorphism-inspired web clock built with HTML, CSS, and JavaScript. This project features a sleek dark theme, a smooth-sweeping analog second hand (like premium watches), and a synchronized digital clock with the current date.

## Features

- **Analog Clock:** Features a smooth sweeping second hand using `requestAnimationFrame` for a seamless, lag-free experience.
- **Digital Clock:** Synchronized 12-hour format digital time display with AM/PM indicators.
- **Dynamic Date Display:** Shows the current day, month, and year instantly.
- **Glassmorphism UI:** A modern, frosted-glass look using CSS pseudo-elements and semi-transparent backgrounds.
- **Dark Theme:** Easy on the eyes with a sleek `#212121` background and vibrant glowing neon accents for the clock hands.

##  Technologies Used

- **HTML5:** Structure and layout.
- **CSS3:** Flexbox, Custom Properties (Variables), Z-index management, and Glassmorphism styling.
- **JavaScript (Vanilla):** DOM Manipulation, `Date` object calculations, and `requestAnimationFrame` for hyper-smooth animations.
